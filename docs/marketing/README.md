## Core rules

1. Keep commercial/storefront content separate from CareNest health functionality.
2. Never imply a purchase changes medical behavior or reminder reliability.
3. Never send CareNest health data to a storefront.
4. Keep repository promotional assets outside `src/CareNest.App`.
5. Preserve the store-safe payload scanner and its external-commerce markers.
6. Use the exact Gumroad destination: `https://ramsandesh.gumroad.com`.
7. Retain a plain-text link wherever an image CTA is used.
8. Do not rewrite historical verification evidence solely to insert newer marketing links.
