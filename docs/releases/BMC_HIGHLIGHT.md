# CareNest Buy Me a Coffee Highlight

CareNest uses `https://buymeacoffee.com/sanskarIN` as its voluntary project-support link.

The support presentation is intentionally separated from medical functionality and user health data.

Implemented surfaces:

- prominent linked support badge at the top of `README.md`;
- highlighted Buy Me a Coffee section in `README.md`;
- highlighted support block in `SUPPORT.md`;
- dedicated in-app About-page support card;
- shared runtime URL through `AppConstants.FundingUrl`;
- GitHub repository funding metadata through `.github/FUNDING.yml`;
- original CareNest support badge asset at `src/CareNest.App/Resources/Images/carenest_support.svg`.

The support badge is an original CareNest project graphic using a coffee-cup motif and CareNest styling. It is not represented as an official Buy Me a Coffee trademark/logo asset.

Financial support remains optional and provides no medical advice, premium health behavior, reminder priority, emergency assistance, health-data access, or application entitlement.
