# BMC Highlight Release Check

Before publishing a store build that contains the external project-support link:

- verify the current distribution platform permits the external voluntary support link in the intended app placement;
- keep the support action separate from health features and health data;
- keep the support language voluntary and non-entitlement-based;
- verify the linked URL is `https://buymeacoffee.com/sanskarIN`;
- verify the original CareNest support badge renders correctly on supported themes/sizes;
- confirm the external browser handoff does not send CareNest health data;
- run the full CareNest CI and CodeQL gates after UI/resource changes.
