# Code of Conduct

CareNest follows a simple contributor covenant: be respectful, constructive, inclusive, and privacy-conscious.

Unacceptable conduct includes harassment, discriminatory language, publishing another person's private information, using real health records as examples without explicit lawful authorization, or intentionally weakening safety/security controls.

Report conduct concerns privately to `sanskarin@outlook.in`. Security vulnerabilities should follow `SECURITY.md` instead of public issue disclosure.
